# Cy_Omics_v2.0

综合蛋白质组学分析平台的统一研发仓库。前端、后端、测试通过同一个 Git 提交版本协作。

| 目录 | 内容 |
| --- | --- |
| `frontend/` | Sites 前端、Node BFF、原型 Worker、前端单元测试 |
| `backend/` | FastAPI 私人项目/原始 TXT 存储、纯 TXT 解析器、后端测试、已审迁移 001–003 |
| `tests/` | 跨 UI/BFF 的合成集成测试、测试支持与执行说明 |
| `docs/` | 开发协作和当前交付边界 |

## 当前边界

这是经过审查的研发源码基线，不是完整的一键生产部署包。真实多用户系统已完成的范围仍以逐项验收为准；真实科研计算、全量端到端测试和全球公开上线尚未完成。页面的演示结果不得当成真实分析。

后端已纳入迁移 001–003 和纯 TXT 解析器源码；解析器已通过有限离线测试与指定真实 TXT 的原值对照，尚未接入上传后的解析 API 或持久化报告。完整依赖锁与正式部署入口仍待完成。固定路径/端口及默认关闭的程序门槛保留；克隆或拉取代码不会自动启用认证、上传、数据库或服务。空数据库需按后端说明核对适用范围和执行顺序，不能直接运行 003。

公开仓库不包含密钥、邮箱授权码、真实用户数据、数据库内容、科学输入文件、服务器运行配置或内部审计记录。临时隔离检查页面中的账号与项目编号已替换为合成占位值，不能用于现有真实账号验收。

## 协作方式

B 用 Sites 完成前端修改后提交到 GitHub；后端和测试也在各自分支提交。审查和测试通过后，A 获取同一个已确认的提交，在独立源码目录中准备版本。服务切换仍单独执行，`git pull` 不会自动部署。

详见 [协作规范](docs/DEVELOPMENT_WORKFLOW.md)、[前端说明](frontend/README.md)、[后端说明](backend/README.md) 和 [测试说明](tests/README.md)。

`docs/SOURCE_BASELINE.json` 保留首次公开源码的历史快照，不是当前版本的全部文件校验清单；后续变更以 Git 提交及对应审查结果为准。

所有科研统计与正式科研图表使用 R 包或 R 标准函数，记录数据处理、参数、版本及图形出处。
