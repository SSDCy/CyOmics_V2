# 原始质控同源桥接源码

只提供提交、按请求编号恢复和状态查询三个固定上游操作。复用既有已验证会话与账号上下文，不向浏览器暴露 bearer，不转发浏览器 cookie/nonce/Owner 字段；执行配置不由桥接选择。未配置明确 request 实现或未开启功能时返回503，不回退原生网络请求。

源码默认关闭，实际服务与私有启动配置均未修改。权限、期限、来源和会话撤回规则没有放宽。可能已提交后的异常返回 submission_unknown，不自动重复 POST；账号上下文变化与业务请求冲突分开处理。源码验证包括157项作者回归和6项独立边界测试，均为合成会话与有界 mock stream，不能替代真实认证/Owner/RLS/计算/浏览器 E2E。
