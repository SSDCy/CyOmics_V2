# 已保存 TXT 的导入报告

本交付增加源代码与有限测试。私有预览切换、真实账号浏览器验收、公开生产发布是不同状态；单元测试通过不代表后三项完成。

## 输入和结果

输入为当前已验证用户在私人项目中保存的 `proteinGroups` TXT。服务器重新确认用户、项目和文件归属并校验原始字节及 SHA-256，使用已审纯解析器读取原始字符串。保留原列名、样本名、零字符串和空字符串；不自动推断处理条件或实验分组。

同一原始文件和解析配置对应稳定的 DatasetVersion 标识。一个不可变数据库行原子保存版本与 ImportReport；相同配置的再次确认复用既有版本。报告包含列和样本列、原始文件行位置、数量统计、解析器版本及配置。完整数值矩阵没有写入新表，不能据此声称标准化、差异分析、FASTA 关联或其他科研计算已完成。

界面区分“原始文件已保存”和“报告已保存”。只有解析请求成功且新的服务器 GET 回查内容一致后，才显示报告已保存。刷新后仅执行 GET 恢复；提交结果不明时只提供手动回查，不自动重发写请求。临时不可用也允许手动重新检查。

## 接口与保护

- `POST /api/v1/uploads/{file_id}/complete`：JSON 仅含 `project_id`，最大 1024 字节。明确点击后才执行。
- 同一路径 `GET ?project_id=…[&version_id=…]`：回查当前配置的报告，不接受请求正文。
- 成功结果严格为 `{datasetVersion, importReport}`，最大 1,114,112 字节。错误结果最大 4096 字节；解析错误只返回有限安全位置，不返回原始单元格内容。
- 认证来自服务端验证。浏览器不能指定用户身份；BFF 维持既有会话、同源和账号上下文检查，私有令牌不返回浏览器。
- 身份、截止时间和并发额度保持到响应发送结束；取消后的实际解析工作未完成时继续占用解析额度。

后端 `create_app(imports_enabled=False)` 和 Node `createPreviewServer(importsEnabled=false)` 默认关闭。私有入口须另行明确启用。接口目前适配 `raw_bytea_v1`，并非项目计划中完整对象存储和历史版本服务。

## 迁移和验证边界

`backend/migrations/004_raw_backed_dataset_imports.sql` 增加不可变版本表及行级隔离。先核对既有 001–003、目标开发数据库、角色和迁移历史；不要把本文件当作通用安装脚本或在已应用的数据库上重复运行。

有限测试覆盖解析、持久化、回查、权限拒绝、错误格式、取消与发送时间限制。合成测试使用显式合成样本，不用于宣称真实科研结果。真实验收使用用户提供的原始 TXT，另行核对首次保存、刷新恢复、版本复用、下载原字节和第二账号拒绝访问。该步骤不涉及正式科研绘图；后续科研绘图仍须使用 R 包或 R 标准函数并记录版本与参数。
