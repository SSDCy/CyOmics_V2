# 原始质控前端源码切片

当前私有 TXT 的紧凑质控区复用已经保存的完整导入版本，不增加上传入口。支持分别选择 Intensity/LFQ、显式提交、四种状态、提交结果未知时按原请求编号回查，以及同一登录会话内刷新恢复引用。样本设计未确认不阻止原始 QC；本模块不做预处理、PCA 或差异分析。

实际应用入口没有启用 rawQcEnabled，服务器、worker 和下载流均未接入。本切片只有默认关闭的源码和合成测试，不表示网页已经能运行质控。执行身份严格按已冻结协议验证；未来使用新的资源配置或完整执行器 bundle，必须先同步审查前后端合同，不能放宽为任意配置。

恢复引用只含 UUID 和家族，存在受会话分区的 sessionStorage；不是凭据或权限。写请求前无法保存恢复引用则不提交。已发出请求后遇到不确定结果保留同一 request_id，只用 GET 核对，不自动再次 POST。后端每次仍独立校验身份和 Owner。重新登录后的历史找回、产物下载、取消和重跑尚未实现。

独立审查修复了已运行任务 started_at 可被后续响应改写的问题。176 项原回归、新2项合同测试和原8项独立边界测试均通过，另4组独立时间边界通过。离线构建包含42项静态资源。当前版本未进行新的真实浏览器或认证/科研 E2E 验收；这些不能由 DOM 合成测试替代。
