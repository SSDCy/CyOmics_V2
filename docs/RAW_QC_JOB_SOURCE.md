# 原始质控任务存储源码候选

本切片保存不可变原始文件版本、请求身份、执行版本与四种任务状态。HTTP 接线、独立 R worker、产物下载和实际启用仍未完成；它不表示网站可以执行质控。

`007_private_raw_qc_jobs.sql` 是待应用的开发库提案。没有提交该迁移，不可自动执行或重复运行既有 001–006。对固定开发 PostgreSQL 17 的两次合成事务测试已实际验证有效入队/领取、Owner 隔离、窄权限、严格数值及产物顺序验证、CAS 和终态保护；两个事务均回滚，新增角色、表、合成数据及父表权限改变均未保留。这不是并发、真实账号 HTTP 或上线证明。

执行注册默认未配置。`raw_qc_limits_v2` 的完整预算使用固定 canonical envelope 摘要；对应受限 R 的真实 tiny 兼容性仍失败，不能注册为可用运行时。后续配置版本变化必须同时更新注册验证与 SQL；不能仅修改摘要使其通过。

范围仅原始 QC，区分空值和原始零值；不要求样本设计先确认，不进行过滤、归一化、填补、PCA 或差异分析。科学脚本及绘图依照既定 R 规范。

离线合成测试：在 backend 目录以独立解释器运行 `python -B -m unittest discover -s tests -p test_raw_qc_contract.py` 与 `test_raw_qc_repository.py`。测试注册、数据和数据库模型均为合成，不连接实际服务。
